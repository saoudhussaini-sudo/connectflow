ENGINEERING HIGHLIGHTS

Built for Reliability & Safety.

01

Automated 10s Loop

Continuous, debounced profile discovery and connection dispatch at steady 10-second intervals without repetitive manual clicks.

02

Global Watchdog Protection

Every DOM query, modal handler, and verification check runs with bounded timeouts. Never hangs indefinitely in waiting states.

03

100-Request Hard Ceiling

Strict session cap at 100 requests. Automatically halts execution and locks further requests to keep your LinkedIn account compliant.

04

Session Deduplication

Extracts unique LinkedIn handles and URNs into a session set. Never wastes cycles or sends duplicate requests to the same candidate.

05

Monochrome Developer UI

Designed in the minimalist Raycast/Linear aesthetic. Pure black and white with high-contrast typography and real-time status pills.

06

Manifest V3 Native

Complies with Google Chrome's latest extension standard using modular service workers and isolated content script messaging.

GETTING STARTED

Install in 60 Seconds

1

Clone Repository

Clone the repository to your local machine using Git.

git clone https://github.com/saoudhussaini-sudo/connectflow.git
2

Open Extensions

Open Google Chrome and navigate to the extensions page.

chrome://extensions
3

Enable Dev Mode

Toggle Developer Mode ON in the top right corner of Chrome.

Toggle: Developer Mode
4

Load Unpacked

Click "Load unpacked" and select the root directory of this extension.

Select connectflow/
